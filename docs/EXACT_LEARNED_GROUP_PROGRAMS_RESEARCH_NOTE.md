# Exact Learned Group Programs: From Finite E8 Words to Affine and Hyperbolic Execution

Date: 2026-09-18  
Status: **PARKED - research note only**  
Owner: SPU research track

This note records a research direction. It authorizes no RTL, ISA allocation,
training run, model download, synthesis, formal campaign, or hardware work.
Any implementation must be covered by a separate owner-authorized contract
with frozen inputs, commands, resource limits, and stop conditions.

## Claim discipline

The following labels are mandatory:

| Label | Meaning |
|---|---|
| **Established mathematics** | A mathematical definition or theorem supported by the cited references and exact checks. |
| **Proposed architecture** | A design hypothesis for SPU; not evidence of benefit. |
| **Experimentally demonstrated** | A result supported by a reproducible, frozen experiment and recorded evidence. |

This note currently contains no experimentally demonstrated results.

## Programme hypothesis

The proposed progression is:

```text
finite E8 generator machine
    -> affine E8 exact translations
    -> bounded or quotient representations of E10 exploration
```

The central hypothesis is:

```text
approximate training -> exact compiled group program
```

The programme should be described as **finite -> affine/translational ->
hyperbolic**, not as a literal progression from 8 to 9 to 10 Euclidean
dimensions.

## 1. Finite E8: primitive reflections and compiled words

**Established mathematics:** The finite E8 Weyl group is generated by eight
simple reflections. Its Coxeter presentation supplies the exact relations

```text
s_i^2 = 1
(s_i s_j)^m_ij = 1
```

where, for simply-laced E8, `m_ij = 3` for connected Dynkin nodes and
`m_ij = 2` for unconnected nodes.

**Proposed architecture:** Treat the eight simple reflections as primitive
instructions:

```text
primitive ISA     = {s_1, ..., s_8}
Weyl word         = s_i1 s_i2 ... s_iL
compiled program  = a frozen discrete word
```

Frequently used words could later be cached as compiler intrinsics or
microcode, while retaining the primitive reflection representation underneath.
This is the intended CPU-like framing:

```text
Coxeter generators = machine instructions
Weyl words         = programs
common words       = intrinsics or microcode
trained network    = compiled program
```

This is a hypothesis about a useful execution model, not a claim that E8 is a
neural architecture or that discrete words preserve task quality.

### 1.1 Arithmetic optimization is representation-dependent

Karatsuba applies to bilinear products inside an exact representation; it does
not reduce E8's dimensionality or replace the Weyl-group structure. For a
quadratic-surds value `a + b sqrt(3)` multiplied by `c + d sqrt(3)`, the direct
four scalar products can be reduced to three:

```text
p0 = a*c
p1 = b*d
p2 = (a+b)*(c+d)

(a + b sqrt(3))(c + d sqrt(3))
  = (p0 + 3*p1) + (p2 - p0 - p1) sqrt(3)
```

For a Weyl reflection, however, the first question is whether the selected
root coordinates make the operation a sparse combination of permutations,
sign changes, additions, subtractions, and constant scales. The intended
design hierarchy is:

```text
root/Weyl structure -> sparse shift/add circuit -> bilinear reduction
```

Only products that remain after the first two stages are candidates for
Karatsuba or another lower-rank bilinear decomposition. Affine E8 should be
handled the same way: derive the affine reflection exactly, then treat
translations as compiled compositions rather than assuming a dense `9 x 9`
multiply.

The post-E8 arithmetic study should compare, for each primitive, a naïve exact
circuit, a structure-exploiting circuit, and any Karatsuba-like variant. Record
exact oracle agreement, common-subexpression count, LUT/DSP usage, latency,
and timing. A result showing that an appropriate coordinate system eliminates
most multiplication is a positive outcome; using Karatsuba everywhere is not
the objective.

## 2. Affine E8: reflections first, translations as macros

**Established mathematics:** Affine `E8^(1)` has nine simple reflections and a
singular generalized Cartan matrix. Its affine Weyl group acts on the
eight-dimensional Euclidean space through affine reflections and translations;
it is not simply a nine-dimensional Euclidean version of E8.

The additional generator `s_0` is an affine reflection associated with the
highest root, not itself a translation. Under one standard convention:

```text
s_0(lambda) =
  lambda - (<lambda, alpha_tilde> - 1) alpha_tilde^vee
```

Translations arise from compositions of affine reflections. Therefore the
proposed ISA boundary is:

```text
primitive instructions = {s_0, s_1, ..., s_8}
translation t_v         = a compiled macro-word
```

This distinction should remain explicit in specifications and documentation.

## 3. Exact scaling without division in the machine

The notation `1/N * t_v` must not be treated as scalar multiplication of a
group element. Use a scaled lattice representation instead:

```text
Lambda_N = (1/N) Lambda_E8
x         = X/N
X         -> X + v
```

The machine stores integer coordinates `X` and applies integer translations.
The scale `N` belongs to interpretation or to an explicitly specified
boundary; the SPU does not perform a division in the translation hot path.

Only after defining a sequence of scaled paths `x_N(t)` should convergence
claims such as `x_N(t) -> x(t)` be investigated. A long reflection word is not
by itself evidence of a smooth continuum trajectory.

## 4. Verification strategy

The initial finite-E8 gate should prove generator relations rather than promise
exhaustive traversal of all `696,729,600` finite Weyl elements. A proposed
verification set is:

1. each generator is an involution;
2. commuting generators commute;
3. adjacent generators satisfy the braid relation;
4. lattice membership is preserved;
5. selected roots and inner products are preserved;
6. the software oracle and any RTL implementation agree bit-for-bit.

Exhaustive testing, if later used, must mean exhaustive enumeration over a
frozen finite-width domain. It must not be described as exhaustive verification
of the unbounded lattice or the entire Weyl group.

## 5. E10 boundary

**Established mathematics:** Hyperbolic Coxeter reflections and Weyl dynamics
are connected to the `E10`/BKL billiard literature, including chaotic
hyperbolic dynamics.

**Proposed architecture:** Investigate whether finite quotients or bounded
representations of E10 Weyl dynamics provide useful high-capacity exact state
navigation.

The stronger claim that E10 provides high-capacity token routing is not
established. An infinite Weyl orbit cannot generally remain in fixed-width
registers without a declared quotient, coordinate bound, modular reduction, or
arbitrary-precision representation. Any quotient must be tested for which
invariants and useful routing properties survive.

## 6. Stage E8-0 falsifier

The first experiment should establish mechanics before model claims:

1. implement the eight exact simple reflections in Python or C++;
2. verify the Coxeter relations exactly;
3. define a fixed-length word with `L` generator slots;
4. give each slot eight trainable logits;
5. train using a declared relaxed or straight-through selection mechanism;
6. freeze every slot to one generator;
7. discard the training machinery;
8. execute only the resulting integer Coxeter word;
9. verify bit-identical results across machines;
10. compare against an ordinary small MLP or linear baseline.

Parity alone is a weak first task because an ordinary network can trivialize it.
The decision question is:

> Does useful learned behaviour survive compilation into the discrete word?

If compilation fails, record the failure mode and stop or revise the hypothesis.
If it succeeds, increase task complexity before introducing `s_0` or affine
translations. E10 is deferred until the affine model has compelling evidence.

## 7. Efficiency hypothesis and transformer boundary

**Research hypothesis:** A learned transformation may be compressible into a
short exact Coxeter program that offers a better accuracy/latency/storage/
energy tradeoff than a dense linear layer on a named workload.

For a word

```text
w = s_i1 s_i2 ... s_iL
```

the relevant comparison is not opcode count alone:

```text
dense-transform cost
    vs
L * generator cost + state traffic + control/decode overhead
```

Word length is therefore a first-class measurement. A short word may reduce
model storage, multiplier/MAC demand, memory traffic, and execution
nondeterminism when its generators compile to cheap integer permutations,
sign changes, or shift-add operations. Conversely, a long sequential word may
replace a parallel matrix multiply with a dependency chain and lose on
latency, throughput, or energy.

**Expressivity boundary:** A pure Weyl-group action is invertible and
structure-preserving. It does not by itself provide the learned projection,
compression/expansion, nonlinear gating, attention weighting, or value mixing
of a normal transformer layer. The initial question must therefore be:

> Which expensive transformer operations can be replaced by learned exact group
> programs without losing useful expressivity?

Candidate scopes include structured projection layers, token transformations,
positional/group structure, routing, or a bounded portion of attention/FFN
machinery. The programme must not claim to replace a transformer wholesale
before a scoped layer-level result exists.

The [structured lattice-head probe](STRUCTURED_LATTICE_HEADS_RESEARCH_NOTE.md)
defines the narrower D4-first comparison. In particular, a shared Weyl
isometry leaves full-dimensional Euclidean similarity unchanged; distinct
head rankings require a separately specified information-changing or
asymmetric operation.

## 8. Efficiency experiment and decision rule

After the E8-0 mechanics falsifier, compare a compiled word model with a
small dense FP32/FP16 baseline on the same task and quality target. Freeze the
generator implementation, word length budget, state width, training budget,
precision, batch shape, and hardware target before comparison.

Record at minimum:

```text
L
model-state bytes
generator and control operations
state/memory bytes moved
latency
throughput
energy, only when physically measured
task accuracy or other predeclared quality metric
```

The comparison must include the cost of decoding, routing, intermediate state,
scales, metadata, and any residual or dense paths. A result such as

```text
100,000 dense parameters -> 300 generator opcodes
```

is not evidence of improvement unless the two systems meet a predeclared
quality target and the complete execution costs are measured fairly.

The hypothesis advances only if a named workload demonstrates a meaningful
improvement in at least one predeclared efficiency metric without unacceptable
quality loss, and without hiding material cost in an omitted downstream
operation. If comparable quality requires very long words, or if GPU/GEMM or
ordinary structured baselines dominate at equal quality and hardware scope,
the specific short-word efficiency hypothesis is parked or closed.

## 9. Exact geometric operator family

E8 should not be treated as the geometry for every workload. The broader
research hypothesis is:

```text
structured geometry -> exact primitive -> machine-learning role
```

Candidate families include:

| Geometry | Exact primitive candidate | Initial ML role |
|---|---|---|
| `D4`, dihedral, and finite permutation groups | permutations, signed reflections, finite group actions | exact CNN rotation/reflection symmetry |
| `A_n`, `D_n`, `E_n`, and related lattices | integer lattice coordinates and root operations | quantization, codebooks, or structured transforms |
| Clifford/geometric algebra | geometric products, involutions, and grade projections | equivariant feature and transformer operators |
| Projective geometry | homogeneous coordinates and incidence operations | vision, perspective, and spatial transforms |
| Conformal geometry | exact or bounded sphere/circle/translation primitives | richer spatial operators, subject to arithmetic cost |
| Polyhedral and spherical geometry | finite rotation-group actions and exact adjacency | discretized directional or spherical processing |
| Graph and simplicial geometry | integer incidence, boundary, and coboundary operators | message passing and topological attention |
| Hyperbolic Coxeter tilings | bounded reflection words or finite quotients | hierarchical routing hypothesis |

These candidates are not interchangeable. A deterministic CNN may benefit more
from a small crystallographic or dihedral group than from E8; robotics and
spatial models may require Clifford, projective, or conformal structure; and
topological models may be better expressed through incidence operators. The
common SPU question is whether the chosen geometry compiles into a small exact
operator set that is useful for the named task.

Before comparing families, freeze the representation, coefficient domain,
state width, overflow or quotient semantics, operator cost, equivariance claim,
and a conventional baseline. Exactness alone is not evidence of improved
accuracy, latency, storage, energy, or sample efficiency.

## 10. Davis-Wilson-inspired cache and gate hypothesis

The Davis-Wilson repository describes a map of the form

```text
Gamma(A) = (Phi(A), r(A))
```

where `Phi` is a bounded continuous/geometric cache and `r` is a discrete
topological residue. This note does not adopt the repository's broader physics
or mathematical claims as established results. It treats the cache/residue
split as an engineering inspiration for a fixed-size state representation.

**Proposed SPU adaptation:**

```text
Gamma_SPU(x) = (geometric cache, discrete algebraic residue)
```

The geometric cache could contain bounded lattice observables, exact loop
signatures, or other declared metrics. The residue could contain a Weyl
chamber, coset, finite-group sector, parity class, or another explicitly
defined discrete value. Both components must have frozen widths and overflow,
quotient, or saturation semantics.

This suggests a two-part exact state machine:

```text
Weyl/Coxeter operator -> exact state proposal
cache/residue gate    -> admissibility, compression, or routing decision
```

A candidate transition is:

```text
x_(t+1) = G_Gamma(x_t)(s_i(x_t))
```

Here `s_i` is an exact transformation and `G` is a deterministic gate selected
from the cache/residue tuple. The gate must not be described as a generic
nonlinearity: its admissibility rule, output state, and information-loss
semantics must be specified and independently testable.

### Closed-path and loop observables

The Davis-Wilson framing motivates testing relational features built from
closed paths rather than only pointwise coordinates. For a finite exact group,
a local loop may be represented by

```text
x_i -> x_j -> x_k -> x_i
```

and summarized by the accumulated group element, conjugacy-class label, trace
surrogate, or another declared invariant. For image data, the analogous probe
is an exact local cell or neighbourhood circulation signature. These are
engineering feature hypotheses only; physical interpretations such as gauge
fields, Wilson loops, or topological charge must not be inferred without a
separate mathematical and empirical justification.

### Falsifiable state-compression experiment

The first cache experiment should ask:

> Can sequence history be compressed into a bounded exact cache plus a discrete
> residue without materially degrading a named task?

Compare a cache/residue state against a same-width dense recurrent or
attention-based baseline. Freeze sequence length, state width, cache
observables, residue domain, update rules, task, training budget, and quality
threshold. Measure task quality, state bytes, update operations, state traffic,
latency, and reproducibility. If physical energy is reported, measure it rather
than inferring it from operation counts.

For a tiny deterministic CNN, a lower-risk probe is:

1. compute exact local loop or circulation features;
2. maintain one declared residue per region or feature cell;
3. gate propagation using only the cache/residue tuple;
4. compare against an ordinary small CNN and an exact local-feature baseline;
5. test robustness when the residue width and cache width are reduced.

Failure to retain quality under bounded state, or a cost increase that exceeds
the saved downstream computation, falsifies this particular adaptation without
disproving the underlying source framework.

## 11. Decision boundaries

This note must not be used to claim:

- improved token routing, model quality, or capacity;
- smoothness from long reflection words;
- exhaustive silicon verification of the finite Weyl group;
- fixed-width execution of unbounded E10 orbits;
- hardware benefit from an unimplemented instruction set;
- acceptance of Davis-Wilson repository claims as established SPU mathematics;
- treating a cache/residue gate as evidence of physical topology or gauge
  dynamics;
- claiming fixed-size reasoning quality without a matched bounded-state
  experiment.

The first acceptable result is narrower: a reproducible exact reflection-word
implementation and a measured answer to whether a trained discrete word
retains useful behaviour relative to named baselines.
