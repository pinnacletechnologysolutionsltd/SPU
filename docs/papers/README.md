# Academic Papers & Preprints

Use the shared [research identity and maturity vocabulary](../RESEARCH_IDENTITY.md)
in new and revised manuscripts. Mark scoped claims **Demonstrated**,
**Experimental** or **Exploratory**, identifying the arithmetic domain, limits,
artifact and evidence. Separate correctness from comparative utility and
software results from hardware qualification. Compare proposed benefits in
determinism, invariant preservation, verification, energy or complexity as
well as speed against appropriate baselines. Preserve negative results and
label possible future integration benefits as hypotheses. Existing manuscripts
retain their dated claims until separately reviewed; this guidance reclassifies
no historical result and establishes no mathematical novelty.

This directory contains LaTeX manuscripts and academic publications detailing the mathematical and hardware foundations of the SPU architecture:

1. **SPU-13 Central Paper** (`spu13_central_paper.tex`): The primary architecture paper for the 13-axis cuboctahedral processing unit.
2. **LUCAS MAC Paper** (`LUCAS_MAC_PAPER.tex`, `LUCAS_MAC_PAPER.md`): Lucas Phinary multiply-accumulate and exact zero-drift cyclic arithmetic.
3. **SU(3) Coprocessor Paper** (`SU3_COPROCESSOR_PAPER.tex`, `SU3_COPROCESSOR_PAPER.md`): Exact rational color-field dynamics coprocessor.
4. **RPLU Jet Paper** (`rplu_paper.tex`): Rational Padé Logic Unit jet algebra.
5. **Theorem-Licensed Typestate Paper** (`theorem_licensed_typestate.tex`, `THEOREM_LICENSED_TYPESTATE_PAPER.md`): Formal state machine guarantees for hardware synthesis.
