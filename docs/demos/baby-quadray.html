Baby’s First Quadray

One four-coordinate point, a proper tetrahedral rotation, its mirror, and an exact weighted-cycle covariance check. The controls use integers and exact integer / Q(√3) arithmetic. Only SVG drawing maps exact projected pixels to screen display.

Why four numbers describe a 3D point: A, B, C and D are weights on four tetrahedral direction vectors. In this lesson's basis the vectors add to zero, so adding the same amount to all four weights changes no point: (A,B,C,D) ∼ (A+k,B+k,C+k,D+k). That one redundancy leaves three independent coordinates. The readout shows a zero-sum representative and the resulting Cartesian point.

1. Coordinates and orientation

Try it: increase A by 1 and predict the Cartesian change from the basis below. Then select Add common +1: all four controls change, but the Cartesian point and projected pixel should stay fixed.

A common offset changes the four numbers but not the point. Even permutations have determinant +1 on the three-dimensional space; odd permutations have determinant −1. An unlabelled regular tetrahedron matches all 24 vertex permutations, while preserving four distinct vertex labels allows only the identity.

Basis: A=(1,1,1), B=(1,−1,−1), C=(−1,1,−1), D=(−1,−1,1). Thus (x,y,z)=(A+B−C−D, A−B+C−D, A−B−C+D).

2. Weighted parity transport

The four-cycle uses exact edge weights w=(1,2,3,2+√3) and state x=(1,0,√3,2). Parity is P(i)=−i mod 4. Both charts retain order 0 → 1 → 2 → 3; parity transports the state and weights once.

This finite example demonstrates covariance of the stated operators and transported data. It does not establish physical chirality, a physical metric, or general dynamics.

3. The GPU boundary

Quadray values and the tetrahedral transform remain exact. The selected rational view transform maps them to a finite (xpixel, ypixel, depth) tuple using nearest-integer, ties-to-even quantization. The T1d simulator then consumes screen pixels and depth; it does not consume Quadray coordinates.

Where each result comes from: The coordinate, rotation/reflection and weighted-covariance readouts above run live in this page's JavaScript using exact integers and exact pairs for a+b√3. The Python regression checks frozen reference values and the separate T1d triangle scene against its ideal and finite-width device models. That simulator does not run the page's JavaScript or validate browser SVG rendering; no physical GPU result is claimed.
