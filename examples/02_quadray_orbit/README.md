# Example 2: Quadray Orbit Transformation

Demonstrates Thomson Quadray 4-axis coordinate transformations and Pell octave rotations.

## The Math
Quadray coordinates define 3D space with 4 symmetric axes from the center of a regular tetrahedron to its vertices:
$[a, b, c, d]$. There are no negative coordinates; Euclidean distance is replaced with exact Quadrance.

## Running in the Emulator
```bash
spu sim examples/02_quadray_orbit/quadray_orbit.sas --steps 30
```
