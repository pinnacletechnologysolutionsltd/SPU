The reported skew/hold violation changed from 2.281 ns / -1.672 ns after synthesis to 3.049 ns / -2.406 ns after placement. The post-route `route_methodology.rpt` no longer contains TIMING-15; routed timing reports 0 failing hold endpoints and +0.011 ns worst hold slack. The `route_timing_summary.rpt` embeds the placement-era methodology table because it was generated before the final route methodology report, so its embedded TIMING-15 row is stale relative to `route_methodology.rpt` and the final routed hold summary.

This is an internal timing result for the specified clocks, not silicon qualification. External VGA timing, reset behavior on hardware, and the RAMB18 control warning remain unqualified. Full reports, checkpoint and logs remain in the ignored build directory above.
