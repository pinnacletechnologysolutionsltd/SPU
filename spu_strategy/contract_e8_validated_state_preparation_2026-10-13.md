## Trusted-session invariant and explicit limits of authority

One Session uses the existing immutable E8 context. The independent-algorithm
context checker verifies roots, Gram, inverse basis, coefficient coordinates
and all1,920 reflection entries once on construction. That setup executes but
its work is NOT instrumented; the Python context factory may already be cached.
Allocate its307,680 logical static bits once per Session model. Multiple state
handles in that Session share the same context. Different Session reports are
separate scopes, not a reconstructed global shared-table peak.

A state key is an identity-only object with no fields; a key is usable only if
the receiving Session's private registry contains that exact object. Registered
values are immutable admitted image tuples. Caller-created keys, raw tuples,
foreign-session keys and retired keys are refused. No public Boolean validity
flag or caller context parameter can establish membership. The module/private

monkey-patching, private-field mutation, memory faults and multithreaded races
are outside this mathematical prototype; this is not a security boundary or
hardware ownership/reset qualification.

## IMPORT schedule

Accept exactly76 bytes. Copy/own the incoming packet, check header/flags and both
context identities, decode eight IDs, then run complete pairwise duplicate and
36-entry Gram admission. Only after validation and capacity/metadata range checks
mint a registry key and publish immutable state. Release incoming buffers after
publication. Failed imports publish no key; record charged prefix/failure and
restore live ownership to the pre-operation inventory.

IMPORT includes parser loops/reads/writes, equality/type/shape/range checks,
admission, UID arithmetic, registry publication and cleanup. Trusted prefix bytes
are a view of context header/hash storage, not newly charged shared tables.
Fixture packet generation and independent output checking are observer work.

## TRANSFORM schedule and closure argument

type/range. Own a scratch descriptor while old state remains live. Read eight
old IDs, eight reflection rows and eight result entries. Check each result type/
range and write the temporary descriptor. Publish the whole immutable tuple in

Handle identity and other registry entries remain unchanged.
