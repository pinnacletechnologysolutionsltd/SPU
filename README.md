# SPU

An experimental project exploring exact arithmetic and geometric computation
in software and on FPGAs.

If you are new here, start with the [short introduction](docs/START_HERE.md).
It explains the ideas, current results and their limits, with detailed evidence
available underneath.

The [documentation](docs/index.md) covers software, hardware and research.
